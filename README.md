 Jay Sam Catacutan - Portfolio

Simple personal portfolio website built with HTML, CSS, and JavaScript.

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── profile.svg
│   ├── project1.png
│   ├── achievement1.png
│   ├── achievement2.png
│   └── achievement3.png
├── documents/
│   └── resume.pdf
└── README.md
```

## Files

- `index.html` - Main HTML file and website structure
- `style.css` - Website design and responsive layout
- `script.js` - Navigation and achievement image lightbox behavior
- `images/` - Profile, project, and achievement images
- `documents/resume.pdf` - Downloadable resume/CV

## Run

Open `index.html` in a browser, or open the folder in VS Code and use a local server such as Live Server.


### Projects

- QuickReport — Flutter mobile app for reporting incidents without an internet connection.
- Student Management System — React JS web application for viewing and managing student grades.
- E-commerce UI Project — E-commerce user interface built with Vite.
